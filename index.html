🔑 Multi API Key Manager

API key disimpan sebagai Cloudflare Worker Secrets, bukan di browser. Worker bisa mencoba key Magic Hour lain saat key utama invalid, kredit habis, atau terkena rate limit.

Untuk beberapa key Magic Hour, buat Secret MAGIC_HOUR_API_KEYS berisi beberapa key dipisahkan koma atau baris baru. Key lama MAGIC_HOUR_API_KEY tetap didukung sebagai cadangan. Jangan tempel key di halaman ini.
